# CLAUDE.md

Follow `AGENTS.md` and all repository source-of-truth documents.

For implementation work:
1. Read the acceptance contract first.
2. Read the milestone section in the implementation plan.
3. Read relevant domain and architecture documents.
4. Inspect current code before proposing changes.
5. Implement only the active milestone.
6. Self-audit against the same acceptance contract.
7. Provide exact-SHA evidence and stop for independent audit.

Do not reinterpret an unresolved business question as permission to invent a rule. Add or reference an `OPEN_ITEMS.md` entry and continue only with unrelated work.

Do not optimize by bypassing print preflight, typed tool boundaries, security controls, or audit evidence.
