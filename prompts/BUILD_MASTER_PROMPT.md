## PRODUCT

Vasin Astra is an installable Windows AI graphic-design and print-production application for a professional printing agency.

The user converses with an AI agent named **Astra**. Astra plans designs, uses connected creative tools such as Photoshop and Illustrator, can later integrate Canva, handles revisions, runs deterministic print preflight, and exports editable plus print-ready production packages.

This is **not** a generic prompt-to-image app. Physical print dimensions, scaling, editable vectors, effective final-size PPI, printer profiles, preflight, and real production output are first-class requirements.

## HARD RULES

1. Implement **one milestone only** at a time.
2. Start with the earliest incomplete approved milestone.
3. Do not invent missing Vasin production rules. Track/quote the relevant OPEN_ITEM and continue only with independent work.
4. Never hard-code 300 PPI as a universal print rule.
5. Separate final physical size from working-document scale.
6. Calculate raster quality at effective final-size PPI.
7. Preserve text/logos/shapes as editable/vector wherever the host permits.
8. Do not flatten an entire final design just because an image generator can create it.
9. Never execute arbitrary shell/script/JSX/VBScript/batchPlay generated by an LLM.
10. All external-tool operations go through reviewed, typed, schema-validated commands.
11. Keep secrets out of renderer, source, config files, logs, tests, and commits.
12. Do not claim Photoshop/Illustrator saved/exported something unless the adapter confirmed it.
13. Do not label output print-ready unless the deterministic preflight gate passes.
14. Do not silently override a blocker.
15. Do not merge to main unless instructed.
16. Do not rewrite working components for style alone.
17. Never start the next milestone in the same handoff.

## SPECIAL IMPLEMENTATION GUIDANCE

### Print Engine
Build it as deterministic pure domain logic with rigorous unit/property tests before embedding it deeply in UI.

### Astra
Treat "Astra" as the product agent, not a fixed model. Implement an AI provider interface and an OpenAI provider.

### Adobe integrations
Implement the generic Tool Protocol and simulator before real Adobe integrations.

For Photoshop, prefer a vetted in-host plugin/adapter using official Photoshop/UXP APIs and a secure loopback bridge.

For Illustrator, respect OPEN_ITEM OI-004. Keep a stable adapter interface. Do not improvise arbitrary script execution.

### Canva
Do not start Canva unless M9 is explicitly activated.

### Large-format
For multi-meter jobs, use scale-aware vector-first production. Never allocate enormous raster documents merely to satisfy nominal 1:1 300 PPI.
