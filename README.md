# Vasin Astra

Vasin Astra is a Windows desktop AI graphic-design and print-production agent for a professional printing agency.

This repository follows a documentation-first, contract-driven implementation process:

**UNDERSTAND → DOCUMENT → CONTRACT → REPOSITORY → BUILD → SELF-AUDIT → INDEPENDENT AUDIT → REMEDIATE → UAT → RELEASE**

Implementation must not begin by guessing product rules. The repository documentation is the source of truth; unresolved business or production decisions belong in `docs/00-governance/OPEN_ITEMS.md`.

The full foundation documentation is being prepared on the `docs/app-maker-foundation` branch.
